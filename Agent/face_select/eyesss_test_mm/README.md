# 综合分心检测系统

基于 **MediaPipe 虹膜检测** + **YOLOv8 物品检测** + **大模型分析** 的综合分心检测系统。

## 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    数据采集层                            │
├──────────────────┬──────────────────┬──────────────────┤
│  MediaPipe 虹膜  │   YOLOv8 物品    │   时序统计       │
│  - 视线方向      │   - 手机检测     │   - 持续时间     │
│  - 眨眼频率      │   - 书/杯子      │   - 变化趋势     │
│  - 注意力等级    │   - 置信度       │   - 频率统计     │
└──────────────────┴──────────────────┴──────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│                    特征融合层                            │
│  构建结构化描述：                                        │
│  "学生视线向右偏移15%，检测到手机(置信度0.85)，         │
│   眨眼频率12次/分钟，持续时长45秒"                       │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│                  大模型分析层                            │
│  输入：结构化特征描述                                    │
│  输出：分心判定 + 原因分析 + 建议                        │
└─────────────────────────────────────────────────────────┘
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `config.py` | 配置文件（API、阈值、提示词） |
| `gaze_detector.py` | MediaPipe 虹膜检测模块 |
| `object_detector.py` | YOLOv8 物品检测模块 |
| `distraction_analyzer.py` | 大模型分析模块 |
| `distraction_detector.py` | 综合检测模块 |
| `test_distraction.py` | 测试脚本 |

## 安装依赖

```bash
pip install opencv-python numpy mediapipe ultralytics requests pillow python-dotenv
```

## 配置

### 1. 配置环境变量

创建 `.env` 文件：

```env
QWEN_API_KEY=your_qwen_api_key
```

### 2. 修改配置（可选）

编辑 `config.py` 修改检测参数：

```python
# 视线检测阈值
class GazeConfig:
    GAZE_X_THRESHOLD = 0.15  # 左右偏移阈值
    GAZE_Y_THRESHOLD = 0.12  # 上下偏移阈值
    EAR_THRESHOLD = 0.21  # 眨眼检测阈值

# 物品检测阈值
class ObjectConfig:
    MODEL_PATH = "yolov8m.pt"  # YOLO模型
    CONFIDENCE_THRESHOLD = 0.25  # 检测置信度

# 大模型分析间隔
class DistractionConfig:
    LLM_ANALYSIS_INTERVAL = 60  # 每60秒分析一次
```

## 检测规则

### 分心判定规则

| 规则 | 条件 | 分数扣除 |
|------|------|---------|
| 检测到手机 | YOLO检测到手机 | -40分 |
| 视线偏离 | 视线方向非居中 | -10~20分 |
| 眨眼频率过高 | >25次/分钟 | -10分 |
| 大模型判定 | 大模型分析结果 | 加权融合 |

### 注意力等级

| 等级 | 分数范围 | 说明 |
|------|---------|------|
| 高 | 80-100 | 专注学习 |
| 中 | 60-79 | 轻微分心 |
| 低 | 0-59 | 明显分心 |

## 大模型提示词

系统会构建如下结构化描述发送给大模型：

```
请分析以下学生学习行为数据，判断是否分心：

【视线数据】
- 视线方向: 向右
- 视线偏移: X=0.180, Y=0.045
- 眨眼频率: 12.5 次/分钟
- 注意力等级: 中

【物品检测】
- 检测到的物品: 手机(0.85)
- 分心物品: 手机(0.85)

【时序统计】
- 当前状态持续时间: 15.2 秒
- 最近30秒视线变化: X变化=0.123, Y变化=0.045
- 最近30秒检测到的物品: 手机: 45次
```

大模型返回：

```json
{
    "is_distracted": true,
    "distraction_level": "high",
    "confidence": 0.85,
    "reasons": ["检测到手机", "视线偏离屏幕"],
    "suggestions": ["建议收起手机", "调整坐姿"],
    "attention_score": 35
}
```
