## 🔧 技术说明

### 配置文件位置

所有模型的配置都定义在 [`app.js`](file://d:\live2d\app.js) 文件的 `MODEL_CONFIGS` 常量中。

### 为什么需要手动配置？

除了 Mao 模型外，其他模型的 `.model3.json` 文件中**没有注册动作和表情文件**。这是因为：

1. 这些模型可能是为 **VTube Studio** 设计的
2. 动作和表情文件直接放在文件夹根目录，而不是标准结构
3. 使用了不同的命名和组织方式

### 如何添加新模型？

如果要添加新的 Live2D 模型，需要：

1. 将模型文件夹放入项目根目录
2. 在 `MODEL_CONFIGS` 中添加配置：

```javascript
'新模型名称': {
    path: './新模型文件夹/模型名.model3.json',
    motions: {
        'Idle': ['动作文件1.motion3.json', ...],
        'Tap': ['动作文件2.motion3.json', ...]
    },
    expressions: [
        '表情文件1.exp3.json',
        '表情文件2.exp3.json',
        ...
    ]
}
```

3. 在 HTML 的下拉菜单中添加选项

## 💡 使用建议

### 推荐使用的模型

1. **Mao** - 功能最完整，动作丰富
2. **Ice Girl** - 表情最多，适合展示各种情绪
3. **Huohuo** - 中文动作名，容易理解

### 注意事项

- Haihupu 和 Pachan 没有动作和表情，只能进行基本的眼神跟踪
- 部分模型的动作可能需要几秒钟加载
- 首次切换模型时可能会有短暂延迟

## 🎯 测试方法

1. 刷新页面（Ctrl + Shift + R）
2. 打开浏览器控制台（F12）
3. 切换不同模型，查看控制台输出
4. 点击"随机动作"和"随机表情"按钮测试

你应该能看到类似这样的日志：

```

✅ 模型信息 - 表情: (6) ['angry', 'baozhen', ...]
```
