# 🚀 快速启动指南

## 三步开始使用

### 第 1 步：启动服务器

**Windows 用户：**
- 双击 `start-server.bat` 文件

**或使用命令行：**
```bash
python -m http.server 8080
```

### 第 2 步：打开浏览器

访问：`http://localhost:8080`

### 第 3 步：享受 Live2D！

- 🖱️ 移动鼠标看模型眼神跟随
- 👆 点击画布播放随机动作
- 😊 点击按钮切换表情
- 🎭 右上角切换不同模型

---

## 💡 提示

- ✅ 推荐使用 Chrome 或 Edge 浏览器
- ✅ 按 F12 可以查看控制台日志
- ✅ 如果模型不显示，请检查是否使用了本地服务器
- ✅ 首次加载可能需要几秒钟

---

## ❓ 遇到问题？

1. **模型不显示？**
   - 确保使用了本地服务器（不是直接打开 HTML）
   - 检查浏览器控制台（F12）是否有错误

2. **动作无法播放？**
   - 等待模型完全加载
   - 查看控制台的可用动作列表

3. **性能卡顿？**
   - 关闭其他标签页
   - 尝试降低浏览器窗口大小
